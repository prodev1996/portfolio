# Rajiv Bhandari / Portfolio

A personal portfolio for software development, application support, and data work. Built with Next.js App Router, React, TypeScript, Tailwind v4, Framer Motion, and Lenis.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000. Production checks:

```sh
npm run lint
npx tsc --noEmit --incremental false
npm run build
```

## Content and design

- `data/projects.ts`: project facts, screenshots, case-study content, and external links.
- `data/project-presentation.ts`: concise display titles, categories, and gallery descriptions.
- `data/site.ts`: contact details and résumé PDF.
- `data/experience.ts`, `data/education.ts`, `data/certifications.ts`: résumé content.
- `app/globals.css`: responsive design tokens, themes, typography, and motion.
- `DESIGN.md`: design direction, audit, and research references.

The homepage prioritizes four projects and links to two additional studies. All six original case-study routes and the résumé route remain available. The skills, experience, and credentials anchors resolve within the shorter background section.

Bricolage Grotesque and Manrope are self-hosted through next/font. The portrait and project screenshots are original portfolio assets. The social card and favicon are generated by Next.js image routes.

## Interaction and accessibility

System-aware light/dark themes, visible keyboard focus, skip navigation, an Escape-dismissable mobile menu, native touch scrolling, reduced-motion support, responsive images, and a printable résumé. Project filters announce their results.

The contact form preserves the existing EmailJS integration and field names. Delivery uses the existing public service configuration. Browser verification checks validation without sending a real message.

## Verification

Production build, TypeScript, and ESLint passed. Browser checks covered 320, 390, 768, and 1440 pixel widths; light and dark appearances; filters; portrait interaction; mobile navigation and Escape focus return; email copying; and required-field validation. All six case studies, résumé, PDF, social image, and favicon returned HTTP 200; an unknown route returned the custom HTTP 404.
